# Omer Avcioglu

**Game developer: Unity & C#, online multiplayer, gameplay systems, 3D characters and animation.** Founder of [McHunter Studio](https://mchunterstudio.com).

I build games from networked co-op prototypes to titles published on Steam and Google Play, and I make tools that speed up production.

## Skills

- **Engines and languages:** Unity (C#), libGDX (Java), Python
- **Multiplayer:** Photon Fusion 2 (shared mode), Netcode for GameObjects, Unity Gaming Services (Relay, Lobby, Matchmaker, Cloud Code, Vivox), Edgegap dedicated servers, Steamworks.NET
- **Gameplay and tools:** physics-driven mechanics, enemy AI, networked state machines, Unity editor tooling and level generators, automated tests
- **3D:** characters in Character Creator, animation cleanup in iClone, FBX pipelines into Unity
- **Video:** trailers and cutscenes in After Effects and Premiere Pro
